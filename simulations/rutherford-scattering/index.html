選修物理 V・近代物理

📚 物理原理與公式

帶正電的 alpha 粒子（4He2+）接近帶正電的原子核時，受到庫侖斥力而偏轉。 多數粒子近乎直線穿過，少數非常接近原子核的粒子會大角度散射，顯示原子的正電荷與大部分質量集中在極小的原子核內。

庫侖斥力 F = k(2e)(Ze) / r²，距離越近，排斥作用越強。
Rutherford 散射角 θ = 2 tan⁻¹[(1.44 Z) / (E·|b|)]，E 以 MeV、b 以 fm 表示。
正面碰撞最近距離 rmin = 2.88 Z / E（fm），由初動能完全轉為電位能。

💡 建議操作

  1. 在「單一粒子」模式改變 b，觀察粒子越靠近原子核，散射角越大。
  2. 比較 Al 與 Au：相同 E、b 下，核電荷數越大，偏轉越明顯。
  3. 提高 E，觀察高速 alpha 粒子較不容易被偏轉。
  4. 切換「粒子束」，累積角度分布並留意大角度事件很少發生。

🔎 思考問題

  1. 為什麼大多數粒子幾乎不偏轉？這反映原子內部有多少空間？
  2. 若正電荷平均分散在整個原子中，還會出現向後散射嗎？
  3. b = 0 時，動能在最近點轉換成哪一種能量？
