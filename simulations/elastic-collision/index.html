一維彈性碰撞

比較碰撞前後的速度、總動量與總動能。

詳細說明與物理原理

速度如何改變？

v₁ = [(m₁ − m₂)u₁ + 2m₂u₂] / (m₁ + m₂)
v₂ = [2m₁u₁ + (m₂ − m₁)u₂] / (m₁ + m₂)

向右為正。無外力時總動量守恆，完全彈性碰撞同時保持總動能。兩球質量相同時交換速度。

模型與觀察

無摩擦直線軌道；瞬時模式的碰撞瞬間完成。開啟牆壁時，牆壁給兩球外力衝量，因此兩球總動量可變；理想固定牆不改變球的動能。

箭頭與球大小為示意；兩球速度向量使用同一比例。等時距軌跡間隔為 0.1 s。更改參數會調整視野；碰撞演示與速度、動量、動能時間圖同步呈現，可用同一時間軸比較。

兩球夾彈簧模式

理想無質量彈簧固定在 A 球右側，原長 4 m；B 球接觸後壓縮彈簧，回到原長便分離。彈簧只推不拉，此模式使用無牆壁軌道，可調整彈簧常數 k。

U = ½kδ²；K₁ + K₂ + U = 定值

δ 為壓縮量。最大壓縮時兩球速度相同，但不一定靜止；動能暫存為彈性位能，分離後速度與瞬時完全彈性碰撞的結果相同。能量圖中綠線是兩球總動能、黃線是彈性位能、虛線是總機械能。
