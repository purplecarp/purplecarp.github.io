# 電流的磁效應

直接以瀏覽器開啟 `index.html`，不需要安裝套件、建置或網路連線。網站入口位於 `physics-simulations.html` 的選修物理 4／第 2 章。

## 操作

- 使用 `simulations/template` 的 Classroom 格式，保留參數收合、大字、演示模式與全螢幕。本頁為靜態觀察，停用播放，隱藏播放、單步、重播、時間軸與速度設定。
- 切換長直導線、單匝環形線圈與有限長螺線管；每種模型都有平面、立體及電流－磁場三個視圖。
- 調整電流大小或反轉方向；線圈可調半徑，螺線管另可調總匝數與長度。
- 平面圖點擊或拖曳移動 P；方向鍵每次移動 1 cm。立體圖拖曳旋轉，方向鍵每次轉 5°；另有方位角、仰角與縮放控制。
- P 固定在 xy 平面，兩個視角共用位置與讀值；立體圖使用 x/y 滑桿調整 P。旋轉與縮放不改變物理狀態。
- 讀取磁場大小、x/y 分量及固定位置的磁場分量對電流圖。
- 磁力線、方向箭頭及測量平面可分別切換。磁場、電流、測量點與座標軸使用放大的實心箭頭；箭頭表示方向，強度以讀值為準。
- 內建基本現象、電流加倍、零電流三組預測題；結論預設隱藏。

## 模型

`model.js` 提供純函式 `state(parameters,time)`，控制以 cm 輸入、計算採 SI 制。空氣芯與穩定電流。長直導線使用無限長解析解；圓環以 128 點中點積分計算畢奧–沙伐定律，螺線管加總 N 個等間距圓環。平面圖為 xy 平面，正 z 朝向觀察者。圓環位於 yz 平面，上下截面屬於同一圓環。立體圖以軸對稱性將場線轉至空間，使用 Canvas 2D 等比例正交投影與線段深度排序。接線、導線厚度、鐵芯、地磁與感應暫態均不包含。

距細導線 0.8 cm 內不顯示非零電流磁場讀值。場線為固定種子的方向積分；數量不隨電流增減，不可藉線條密度跨模型定量比較。螺線管同時呈現逐匝中心實算值與長管近似值，兩者不要求相等。

## 驗證

在專案根目錄執行：

```sh
node --test simulations/current-magnetic-field/physics.test.cjs
node simulations/current-magnetic-field/browser.test.cjs
```

瀏覽器檢查需要 Node 22+ 及 Chrome 或 Edge；可用 `CHROME_PATH` 指定瀏覽器。以隱藏視窗檢查三種模型的三種視圖、旋轉不改變讀值、時間控制不可見且無動畫循環、預測題、測量點、零電流、排除區，以及 1024×768、1180×820、1366×768、768×1024、390×844 一般／演示版面。截圖寫入系統暫存目錄。

平板觸控／電視遠距可讀性待實機確認。此頁可直接離線開啟；未自動部署。
