電流的磁效應

切換長直導線、環形線圈與螺線管；用平面測量磁場，用立體視角看見導線與磁場的空間關係。

詳細說明、公式與模型限制

操作與視角

每種模型都有「平面視角」、「立體視角」與「電流－磁場」圖。平面圖可用單指拖曳測量點 P；立體圖用單指拖曳旋轉，或使用方位角、仰角與縮放的滑桿／加減按鈕。視角歸位保留物理參數。

P 點固定在 xy 平面，兩種視角共用同一位置與讀值。立體視角可透過測量位置 x、y 滑桿移動 P；旋轉相機不會改變磁場數值。+z 為平面圖朝向觀察者的方向。綠色表示磁場，橙色表示傳統電流，黃色表示 P 點。

長直導線與右手定則

B = μ₀|I| / (2πr)

導線視為沿 z 軸的無限長細導線，r 是到導線的垂直距離。正電流沿 +z，平面圖以 ⊙ 表示出紙面，此時磁場逆時針；負電流以 ⊗ 表示入紙面。右手拇指沿電流，四指彎曲方向就是磁場方向。立體圖僅顯示無限長導線的一段。

單匝環形線圈

Bₓ(x) = μ₀IR² / [2(R² + x²)³ᐟ²]；B中心 = μ₀|I| / (2R)

圓環位於 yz 平面，軸線沿 x。平面圖的上下兩個截面屬於同一個完整圓環，立體圖顯示完整形狀。正電流在上方截面沿 +z、下方沿 −z，中心磁場沿 +x。右手四指順電流彎曲，拇指指向中心磁場。

有限長螺線管

長管內部近似：B ≈ μ₀N|I| / L

以 N 個圓環均勻排列於長度 L 內，各匝位於等分區間的中點，磁場由各匝畢奧–沙伐定律積分相加。平面圖每對上下截面對應立體圖的一匝。保留端點與外部磁場；不模擬螺旋連接線、引線與導線厚度。正電流時管內磁場朝右，右端為 N 極，外部磁場返回左端。

μ₀NI/L 僅為長管內部、遠離兩端的近似。畫面列出中心實算值及長管近似，短管兩者不必相等。

靜態觀察與數值顯示

本模擬顯示穩定電流的磁場。調整參數後立即更新，不需要播放或時間軸；較大的實心箭頭表示磁場與傳統電流方向，不代表粒子運動或傳播速率。

旋轉、縮放及顯示選項不改變物理條件；恢復預設還原全部參數與顯示設定。測量位置以 cm 輸入，計算使用 SI 單位，讀值以 μT 顯示。

採 μ₀ ≈ 4π × 10⁻⁷ T·m/A，空氣芯，忽略鐵芯、地磁與感應暫態。圓環採 128 點中點積分。距導線 0.8 cm 內隱藏非零電流的讀值與場線，避免細導線奇異點與近線數值誤差；此範圍不代表真實線徑。

磁力線採固定種子，數量不隨電流大小改變，不應用密度跨模式比較強弱；箭頭長度固定，只表示方向。電流－磁場圖在同一模型內使用固定縱軸：長直導線 ±50 μT、環形線圈 ±200 μT、螺線管 ±1500 μT；切換模型會改變尺度，讀值超界時會標示。磁場分量與電流呈線性，圖表使用帶正負號的 Bᵧ（長直導線）或 Bₓ（線圈）。立體採等比例正交投影及線段深度排序，遠側部分較暗；可關閉磁力線以清楚觀察繞線。
