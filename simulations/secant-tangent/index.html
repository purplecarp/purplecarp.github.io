動手探索

範圍 −2 ～ 2；P = (a, f(a))

範圍 0 ～ 2；Q = (a + h, f(a + h))

先看一段，再看一瞬間

1 · 函數在說什麼？

函數把輸入 x 對應到輸出 f(x)。圖上的 P 與 Q，是兩組「輸入、輸出」。斜率表示 x 每增加 1 單位，f(x) 改變多少；負斜率表示下降。

本頁的 x、f(x) 是無單位的數學量。若把橫軸看成時間 t（秒）、縱軸看成位置 s（公尺），斜率的單位就是公尺／秒。

2 · 割線：一段區間的平均

連接兩個不同點 P、Q 的直線叫做割線。用總變化量除以輸入的變化量，就得到平均變化率。

m割線 = Δy / Δx
= [f(a + h) − f(a)] / h，h ≠ 0

平均變化率不是兩個函數值的平均，也通常不等於兩端瞬時變化率的平均。

3 · 切線：某一點的瞬時

固定 P，讓 Q 從左右兩側越來越接近 P。若割線斜率都趨近同一個有限值，這個極限就是 P 點的導數，也就是瞬時變化率。

f′(a) = limh → 0 [f(a + h) − f(a)] / h

趨近 0 不等於直接代入 0。h = 0 時兩點重合，差商成為 0 / 0，無法定義割線斜率；切線斜率來自極限。切線也不一定只和整條曲線相交一次。

把圖形變成速度：s(t) = t²

若物體在 t 秒時的位置為 t² 公尺，從第 1 秒到第 3 秒，平均速度為 (9 − 1) / (3 − 1) = 4 公尺／秒。但第 1 秒的瞬時速度為 s′(1) = 2 公尺／秒。把時間區間縮成第 1 秒到第 1.01 秒，平均速度變成 2.01 公尺／秒，逐漸接近 2。

這裡討論的是「位置變化／時間變化」的速度；若物體中途折返，平均速率則要以總路程除以時間計算。
