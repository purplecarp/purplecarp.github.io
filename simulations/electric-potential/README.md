# 電位地形教學模擬

直接以瀏覽器開啟 `index.html`，或從網站「選修 IV → 電勢能與電位、等位面」進入。純 HTML、CSS、JavaScript 與 Canvas 2D，核心功能無外部網路依賴。

- `index.html`：課堂演示／詳細說明、公式、模型限制與教學指引。
- `style.css`：本頁專用響應式排版，引用既有 `../../css/simulations.css`。
- `physics.js`：SI 單位的解析電位／電場疊加與 RK4 切面場線。
- `simulation.js`：Canvas 2D 立體投影、等位線、編輯器、探針、場線示意動畫與 A／B 比較。
- `physics.test.cjs`、`browser.test.cjs`：物理及瀏覽器回歸檢查。
- 網站入口更新於 `../../physics-simulations.html`。

## 操作

預設進入課堂演示模式。單指拖曳立體地形可旋轉視角；在「俯視配置」點選／拖曳物件，點空白處移動探針。控制面板可以輸入精確座標、電量、面電荷密度，或切換連續放置工具。使用「＋」按鈕可持續新增物件；不設固定物件數上限。

每個點電荷可調整 x、y、z 與 q。每片無限平板可調整定位點 x、y、z，法向方位角、法向仰角與 σ。地形顯示水平切面 z = 常數上的電位，高度是電位，不是空間 z 座標。

曲面／色圖、等位線、場線、物件標記皆可獨立開關。探針顯示 V、完整 |E| 與 E_z；窄螢幕保留前兩項。A／B 比較儲存各自物件配置，共用目前切面、視野與電位尺度。

播放僅為場線光點方向示意，不模擬帶電粒子動力學。播放／暫停保留進度；重播保留參數並歸零、暫停；單步增加 0.1 s；提供 0.25×、0.5×、1×。改變電荷、平板或切面後歸零、暫停。返回背景自動暫停。

## 三組教學情境

1. 單一 +1 nC 點電荷：比較距離，辨認 V ∝ 1/r、|E| ∝ 1/r²。
2. +2 nC 點電荷：只改電量，與第一組同尺度比較 V 與 E 加倍。
3. x = ±2 m、σ = ±0.1 nC/m² 平行平板：檢驗板間均勻場與板外抵銷。此情境使用 ±50 V 色階；畫面持續顯示目前尺度。

各組都有預測題、觀察提示與可主動揭示的結論，答案預設隱藏。

## 模型與限制

真空、固定點電荷、均勻無限大非導體薄平板，採解析疊加，不含導體感應。每個點電荷項以無限遠為零，各平板項以各自板面為零。含無限平板時不能把無限遠設為總電位零點；比較不同平板配置宜觀察電位差與坡度。

理想點電荷處的 V、E 未定義；曲面略去距點電荷 0.12 m 內區域，未以平滑近似修改庫侖公式。超出電位範圍的高度與顏色截斷、並顯示提示；探針仍顯示原始值。平板上場不連續，探針電場顯示不定義。平板圖示僅是其與切面的交線或定位點，物理計算仍使用無限平板。

離開切面的電場以 (E_x, E_y) 在切面內的積分曲線表示，介面及說明會標示這不是完整三維電力線的投影。曲線數量、標記大小及光點速度為示意。等位線採固定解析度三角網格插值，圖形是數值近似；太密時提示增大間距。物件數增加時效能下降。

## 驗證

在本目錄執行：

```text
node physics.test.cjs
node browser.test.cjs
```

瀏覽器測試需 Node.js 22 以上及 Chrome／Edge；可用 `CHROME_PATH` 指定執行檔。以隱藏的無頭瀏覽器執行，截圖與獨立瀏覽器資料放在作業系統暫存資料夾。

已驗證：

- 庫侖定律手算值、距離倍率、電量倍率、正負號、電偶極中點、離切面電場。
- 無限平板常場、兩片異號平板疊加、三維 E = −∇V 數值交叉驗證、參數極值與奇異點。
- 場線方向、正點電荷 16 條對稱場線、遇平板停止。
- Chrome：1024×768、1180×820、1366×768、1280×800、768×1024、390×844；無橫向捲動，主要操作未超出視窗。
- 大字 1024×768、devicePixelRatio = 2、演示／詳細模式、收合面板、觸控拖曳、指標釋放。
- A／B、探針、圖層、空配置、負電荷、傾斜平板、恢復預設、播放／暫停／重播／單步及背景暫停。
- 瀏覽器執行無 JavaScript 例外；已檢視正負地形、平板、俯視及直向畫面截圖。

平板觸控／電視遠距可讀性待實機確認；實機全螢幕與 Safari 尚未驗證。
