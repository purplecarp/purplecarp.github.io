# 法拉第電磁感應定律

直接開啟 `index.html`，或從網站「第 3 章：電磁感應」進入。沿用 `simulations/template` 的 Classroom 介面，無 CDN、建置工具或新增套件。沒有修改共用課堂元件。

## 操作

- 磁鐵／環形線圈：拖曳物體或標示把手，亦支援位置滑桿與加減按鈕。方向鍵移動磁鐵，Shift＋方向鍵移動線圈。停手或放開後電流歸零。
- 自動往復：選擇磁鐵、線圈或兩者一起移動，再播放。提供單步、時間軸、重播及教學預設。
- 交流／直流發電機：立體線圈、軸、引線、滑環／換向器、固定電刷及閉合負載。拖曳空白處或使用視角控制旋轉觀察。交流／直流切換保留當下轉角。
- 波形可選每匝磁通量、線圈感應電動勢、負載電流。直流電流圖以相同尺度疊加交流參考。
- 接環／方向頁放大呈現接環與電刷，磁鐵模式則呈現從右側觀察的線圈電流方向。

## 模型

`model.js` 是以 SI 單位計算的純函式。磁鐵實驗採平滑有效磁通函式，感應電動勢由其解析梯度及相對速度計算；不是有限尺寸條形磁鐵的精確場解。發電機使用 `Phi = BA cos(theta)`、`emf = NBA omega sin(theta)`，直流外部輸出為理想全波整流。無自感、電刷壓降或機械回授；箭頭、代表匝與接環間隙為教學示意。頁面詳細說明列出完整假設與 OpenStax 來源。

Classroom 擁有唯一動畫循環。手動模式以指標事件估算相對速度，120 ms 無新位移即歸零，使用受限的操作歷史；與自動演示時間軸分開。物理參數改變會重設自動演示。暫停保留瞬時讀值；轉速設零才代表真正停止。

## 驗證

在專案根目錄執行：

```text
node --test simulations/faraday-induction/model.test.cjs
node simulations/faraday-induction/browser.test.cjs
```

瀏覽器測試需 Node 22+ 與本機 Chrome／Edge（或指定 `CHROME_PATH`）。測試以隱藏瀏覽器直接開啟本地 HTML，截圖寫入系統暫存資料夾。

涵蓋解析微分、手算發電機、零值與極值、磁極／速度反轉、一起移動零電流、交流／直流波形、滑鼠及模擬單指觸控、播放與時間倒拖、視角不改變物理讀值、背景暫停、全螢幕與大字。檢查 1024×768、1180×820、1366×768、768×1024、390×844 的一般／演示模式。

平板觸控／電視遠距可讀性待實機確認。此變更未部署。
