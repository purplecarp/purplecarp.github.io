# 3D 水波槽：雙點波源干涉

直接以瀏覽器開啟 `index.html`，或從網站「高中物理教材」的既有 3D 水波槽卡片進入。無外部執行期、CDN、網路或建置需求；可放在 GitHub Pages。

## 使用方式

- 拖曳 3D 畫面旋轉、滾輪縮放；鍵盤方向鍵調整角度，Home 回到預設。
- 水面與下方實體屏幕，以及右側屏幕正面圖，使用同一個模擬時間。
- 暫停後「逐格」前進 1/24 週期；播放倍率只影響時間流速。
- 點擊屏幕或用方向鍵移動 P，檢視同一水平座標水面的波程差、振幅與兩週期位移圖。Home 回到 P = (0, 15) cm。
- 同相、反相、波源間距、頻率與單源振幅可即時調整；支援單源對照。
- 預設：波長 6 cm、間距 10 cm、頻率 1 Hz、單源振幅 0.15 cm。波長可在 4–20 cm 之間以 0.5 cm 間隔調整；水深固定為 4 cm，槽底至屏幕固定為 3 cm。重設會恢復預設波長。
- 頁面沿用 simulations/template 的 classroom 共用樣式，提供淺色面板、藍色按鈕與大尺寸控制項。
- 光影投影呈現折射後的光強；振幅分布呈現時間不變的水波包絡。3D 下方實體屏幕始終顯示光影投影。
- 黃色節線、S₁/S₂ 與 P 是參考標記，不是光學陰影。P 的屏幕標記是相同水平座標，不是穿過水面 P 的光線落點。
- 系統偏好減少動態時，初始為暫停，可手動播放。

## 模型

水面（cm、s）：
η = A₁ cos(kr₁ − ωt) + A₂ cos(kr₂ − ωt + φ)
k = 2π/λ，ω = 2πf，S₁ = (−d/2, 0)，S₂ = (d/2, 0)。

波程差 Δr = r₂ − r₁；局部相位差 δ = kΔr + φ。雙源等振幅的包絡為 2A |cos(δ/2)|。節線滿足 δ = (2m+1)π，以解析雙曲線取樣。使用穩態、等振幅模型，忽略徑向衰減、邊界反射與色散。波長可在 4–20 cm 之間以 0.5 cm 間隔調整；頻率可透過滑桿或數值欄位在 0.25–2 Hz 之間調整（間隔 0.05 Hz），波速依 v = fλ 更新；水深固定為 4 cm，槽底至屏幕固定為 3 cm。水深只參與光線追蹤，不改變波速。

投影使用幾何光學：
1. 均勻垂直平行光入射到真實起伏水面。
2. 從解析水面梯度求法向量，依向量 Snell 定律由空氣折射至水（n = 1.333）。
3. 穿過水平槽底後折射回空氣，與下方屏幕求交。
4. 將等功率光線以雙線性權重累加至固定 60 × 60 cm 屏幕；屏幕外光線不計入捕獲功率。邊緣插值權重保留在邊緣像素，以維持捕獲光能守恆。
5. 使用固定曝光映射 255 × (1 − exp(−ln(2) × I/I₀))，平靜水面 I/I₀ = 1 顯示中灰；不逐幀自動正規化。

忽略玻璃厚度、側壁遮擋、Fresnel 反射、吸收、繞射與多次反射。數學點波源中心的法向量使用垂直法向量；其他位置由解析梯度求出。全反射光線不加入屏幕。此為教學模型，非實驗裝置的校準預測。

水面起伏放大只改變 3D 水面的垂直顯示，不改變光學計算。光路的虛線連接實際入射點與放大後顯示點。在俯視角，水面會遮擋下方屏幕，右側正面圖仍可同步觀察。

## 檔案

- `model.js`：水面疊加、包絡、波程差與節線（瀏覽器／CommonJS 共用）。
- `optics.js`：解析法向量、折射、光線求交與光強累加。
- `app.js`：Canvas 3D 正交投影、畫面同步、控制與觀測圖。
- `style.css`、`index.html`：響應式繁體中文介面。

## 驗證

在專案根目錄執行：

```sh
node --check simulations/ripple-tank-3d/app.js
node --test tests/ripple-tank-3d.test.cjs tests/ripple-tank-optics.test.cjs
node tests/ripple-tank-browser.cjs
```

瀏覽器測試需要已安裝的 Playwright 與 Microsoft Edge；可用環境變數 `RIPPLE_PLAYWRIGHT` 指向 Playwright 套件。測試直接開啟本機 HTML，不需伺服器，截圖輸出至系統暫存目錄。

11 項既有數學測試涵蓋同相／反相、半波長路徑差、向外傳播、週期性、節線、單源與極端值、解析梯度、Snell 定律、平靜水面均勻照度、屏幕距離、捕獲能量與取樣收斂。瀏覽器測試涵蓋播放／暫停／逐格、光源開關、兩種屏幕模式、觀測點、視角、參數、重設、手機版面與減少動態偏好。
